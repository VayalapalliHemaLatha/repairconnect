# RepairConnect

RepairConnect is a frontend job portal prototype built using **Next.js**.

## Features

- Login & Signup (Employer / Technician)
- Employer Dashboard
- Post New Job
- Job Details & Applicants
- Technician Dashboard
- Browse & Apply Jobs
- Technician Profile
- Responsive UI
- Mock data (No backend / No database)

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```
